# Project Instructions & Rules

1. **Routing**: Always use proper React Router (`react-router-dom`) for navigation. Never use `window.location.href` or manual page reloads for SPA routing.
2. **TypeScript Strictness**: Never use `any`. Always define and use proper TypeScript interfaces/types for API responses and component props.
3. **No Shell/Git/Build modifications**: Don't touch `npm run build`, `git`, and the `shell` unless explicitly asked. Just fix the code.
4. **Accuracy over speed**: Strictly give very slow but very accurate responses. Do not rush to quick but inaccurate solutions. No spaghetti code. No hacks until proven necessary.
5. **No surprises**: Don't do what you're not asked to do, and always know what you're doing.
